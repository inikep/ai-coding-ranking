Languages covered

The ranking targets C/C++. Two columns explicitly describe their language coverage: Atlas (SWE Atlas repositories in Go, Python, TypeScript, JavaScript, C and C++, with no per-language scores) and C++ mig (code ported into C++). The other benchmarks:

  • DeepSWE: TypeScript, Go, Python, JavaScript and Rust (113 tasks). No C or C++.
  • FC AA and FC Cog: both use FrontierCode 2.0. The full language distribution is not published; examples include JavaScript and a Kotlin Android SDK.
  • FSWE V2: includes C systems work (FFmpeg libswscale) and tasks such as reimplementing git in Zig. No language-specific aggregate is published.
  • TB 4.0 and Cursor: full language distribution not published. Terminal-Bench 4.0 is split by task area, not language.
  • C++ mig source programs: Python, Java, Kotlin and Rust.

Together the benchmarks cover at least Python, TypeScript, JavaScript, Go, Rust, Java, Kotlin, C and C++. Most of the table measures general software-engineering ability, which carries over between languages, but the order can change by language. In Code Migration, Claude Fable 5.2 leads on ports into C++ (86.1%) although Claude Sonnet 5.5 leads overall; Gemini 4 Argon does better in C++ than overall; GLM 5.3 drops from 49.6% into Python to 26.9% into C++, below the smaller GLM 5.3 Flash. Gemini 4 Neon has no C/C++ result yet.

Recommendation

For a controlled head-to-head evaluation, start with Claude Fable 5.2, Claude Opus 5.5, GPT-6.2 Astra and Gemini 4 Carbon. Fable 5.2 is still the strongest model overall and also leads SWE Atlas and C++ migration; compare it at high effort against Opus 5.5 at max effort. GPT-6.2 Astra nearly matches Fable 5.2 on Artificial Analysis’s FrontierCode 2.0 at the same price, but until DeepSWE and FrontierSWE results arrive it is a better fit for code review than for long autonomous tasks. Trial Gemini 4 Carbon before its introductory price ends on November 30, and run Gemini 4 Neon next to it: Neon leads CursorBench 4.1 and the Coding Agent Index and costs less than Carbon's regular price, but has no C/C++ or long-horizon result yet. Kimi K3.1 Pro remains worth a trial for long terminal and agentic tasks. For high-volume work such as test-failure triage and first-pass review, Gemini 4 Hydrogen, GPT-6.1 Terra and Claude Haiku 5.5 are the cheaper options. Where C++ quality matters more than price, Claude Sonnet 5.5 ($2 / $10) scores 84.4% on ports into C++, far ahead of the cheapest models with a result. Test them on real InnoDB concurrency issues, replication bugs, crash recovery, memory-safety problems, complex code reviews and MTR regression tests.

Method

Ratings weigh large-repository understanding, complex debugging, code review, long-horizon engineering and C/C++ correctness. They are estimates, not a formula over the benchmarks: benchmarks use different agent harnesses and reasoning settings, and the table shows each model's best published configuration. SWE Atlas and Code Migration explicitly describe C/C++ coverage; FrontierSWE also includes C systems tasks (see Languages covered). SWE-bench Verified, SWE-bench Pro, SWE-bench Multilingual, Aider Polyglot and LiveCodeBench are not shown because they have results for few or none of these models. DeepSWE combines Mercor results with vendor publications (†), some of which cite Datacurve evaluations; publication provenance is not proof of an independent run. FC AA and FC Cog both use FrontierCode 2.0 but different harnesses. FC Cog replaces the legacy 1.1 column; its scores must not be interpreted as changes on the same test. FSWE uses V2 mean@5 across 34 tasks, with five trials and a 20-hour budget per trial. Prices are indicative; where OpenRouter lists several rate tiers, the vendor's standard tier is shown.

DeepSWE publication provenance: Meta’s Muse Wonder model card and Thinking Machines’ Inkling 2 Small launch credit Datacurve for their DeepSWE results; Kimi’s launch describes its own Claude Code evaluation. The † marker identifies the publication used, not a common test harness.

Six models have a verified mini-SWE score. The official leaderboard supplies Opus 5.5, GLM 5.3 Flash and MiniMax M3.1 Flash. Google reports Carbon with mini-swe-agent and Neon and GPT-6.2 Sol with its vision variant.

*Methodology*

Quality ratings prioritize large-repository understanding, complex debugging, code review, long-horizon engineering, and C/C++ correctness. SWE-bench, LiveCodeBench, and other SWE evaluations also inform the qualitative assessment where comparable data exists. The main table uses independent results; where none exists, it shows another independent run (`‡`) or a vendor-reported result (`†`). The FC2 column is new: it is the only one of these benchmarks with results for most new models.

*GPT-6.2 Astra* ranks #3 with 9.6, tied with Gemini 4 Carbon. Independent results so far are better than GPT-6 Astra's: 63.1% on Vals AI Terminal-Bench 4.0 (#6, tied with Gemini 4 Carbon; GPT-6 Astra 59.6%) and 49.0% on Artificial Analysis FrontierCode 2.0 at xhigh (#2, 0.1 points behind Claude Fable 5.2; GPT-6 Astra 42.4%). Its Artificial Analysis Intelligence Index is 62 (Fable 5.2: 65, GPT-6 Astra: 57), and Epoch AI puts it level with Fable 5.2 on its Capabilities Index (174). But Artificial Analysis says its coding is flat: its Coding Agent Index is unchanged from GPT-6 Astra. Early users are critical of long agentic work: they report that it stops early on end-to-end builds, is hard to steer and makes nearly twice as many tool calls. One reviewer still credits it with catching issues other models missed in code review. It has no DeepSWE, FrontierCode 1.1, CursorBench or FrontierSWE result yet, so it ranks level with, not above, GPT-6 Astra. It costs $8 / $40 up to 272K tokens of context, 20% less than GPT-6 Astra ($16 / $60 above 272K).

*GPT-6.2 Sol* ranks #8 with 9.0, the same as GPT-6.1 Sol. Artificial Analysis, however, measures a 3-point drop on its Coding Agent Index, driven by a 14-point drop on SWE-Atlas-QnA, where it more often leaves out key facts. It keeps GPT-6.1 Sol's price, $2 / $10.

*Recommendation for Percona Server for MySQL*

Top candidates for a controlled head-to-head evaluation are *Claude Fable 5.2, Claude Opus 5.5, GPT-6.2 Astra, and Gemini 4 Carbon*. Fable 5.2 is still the strongest model overall; compare it at high effort against Opus 5.5 at max effort. GPT-6.2 Astra now costs the same as Fable 5.2 and matches it on FrontierCode 2.0, but early reports of stopping early and being hard to steer make it a better candidate for code review than for long autonomous tasks until DeepSWE and FrontierSWE results arrive. Trial Gemini 4 Carbon before its introductory price is reported to end on November 30. Kimi K3.1 Pro remains worth a trial for long-running terminal and agentic tasks. For high-volume work such as test-failure triage and first-pass code review, Gemini 4 Hydrogen, GPT-6.1 Terra and Claude Haiku 5.5 are the cheaper options. Test them against real InnoDB concurrency issues, replication bugs, crash recovery, memory-safety problems, complex code reviews, and MTR regression tests.

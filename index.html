Languages covered

The ranking targets C/C++, but only two columns state that they test it: Atlas (SWE Atlas repositories in Go, Python, TypeScript, JavaScript, C and C++, with no per-language scores) and C++ mig (code ported into C++). The other benchmarks:

  • DeepSWE: TypeScript, Go, Python, JavaScript and Rust (113 tasks). No C or C++.
  • FC 1.1: languages not listed. Cognition says it triples the number of languages in SWE-Bench Pro, and one published example task is a C++ repository.
  • FC 2.0, TB 4.0, Cursor, FSWE: languages not published. FrontierCode 2.0's sample tasks are JavaScript and a Kotlin Android SDK, FrontierSWE's example is reimplementing git in Zig, and Terminal-Bench 4.0 is split by task area, not language.
  • C++ mig source programs: Python, Java, Kotlin and Rust.

Together the benchmarks cover at least Python, TypeScript, JavaScript, Go, Rust, Java, Kotlin, C and C++. Most of the table measures general software-engineering ability, which carries over between languages, but the order can change by language. In Code Migration, Claude Fable 5.2 leads on ports into C++ (86.1%) although Claude Sonnet 5.5 leads overall; Gemini 4 Argon does better in C++ than overall; GLM 5.3 drops from 49.6% into Python to 26.9% into C++, below the smaller GLM 5.3 Flash.

Recommendation

For a controlled head-to-head evaluation, start with Claude Fable 5.2, Claude Opus 5.5, GPT-6.2 Astra and Gemini 4 Carbon. Fable 5.2 is still the strongest model overall and also leads both C/C++ columns; compare it at high effort against Opus 5.5 at max effort. GPT-6.2 Astra matches Fable 5.2 on FrontierCode 2.0 at the same price, but until DeepSWE and FrontierSWE results arrive it is a better fit for code review than for long autonomous tasks. Trial Gemini 4 Carbon before its introductory price ends. Kimi K3.1 Pro remains worth a trial for long terminal and agentic tasks. For high-volume work such as test-failure triage and first-pass review, Gemini 4 Hydrogen, GPT-6.1 Terra and Claude Haiku 5.5 are the cheaper options. Where C++ quality matters more than price, Claude Sonnet 5.5 ($2 / $10) scores 84.4% on ports into C++, far ahead of the cheapest models with a result. Test them on real InnoDB concurrency issues, replication bugs, crash recovery, memory-safety problems, complex code reviews and MTR regression tests.

Method

Ratings weigh large-repository understanding, complex debugging, code review, long-horizon engineering and C/C++ correctness. They are estimates, not a formula over the benchmarks: benchmarks use different agent harnesses and reasoning settings, and the table shows each model's best published configuration. Only SWE Atlas and Code Migration state that they include C or C++ (see Languages covered). SWE-bench Verified, SWE-bench Pro, SWE-bench Multilingual, Aider Polyglot and LiveCodeBench are not shown because they have results for few or none of these models. Independent results are preferred; vendor results appear only where nothing else exists and are marked †. Prices are indicative; where OpenRouter lists several rate tiers, the vendor's standard tier is shown.

*Languages covered*

The ranking targets C/C++, but only two columns state that they test it: *ATLS* (SWE Atlas: Go, Python, TypeScript, JavaScript, C and C++ repositories; no per-language scores) and *MC++* (code ported into C++). The other benchmarks cover:
- DEEP — TypeScript, Go, Python, JavaScript and Rust (113 tasks). No C or C++.
- FCOD — languages not listed; Cognition says it triples the number of languages in SWE-Bench Pro, and one published example task is a C++ repository (jsonschema).
- FC2, TB4, CURS, FSWE — languages not published. FrontierCode 2.0's sample tasks are JavaScript and a Kotlin Android SDK; FrontierSWE's example is reimplementing git in Zig; Terminal-Bench 4.0 is split by area (software, science, ML, operations, hardware, security, media), not by language.
- MC++ source programs — Python, Java, Kotlin and Rust (Code Migration's other columns score the same ports into those languages; its overall score also includes COBOL to Java).

Together the benchmarks cover at least Python, TypeScript, JavaScript, Go, Rust, Java, Kotlin, C and C++. Most of the table therefore measures general software-engineering ability, which carries over between languages, but the order can change by language. In Code Migration, Claude Fable 5.2 leads on ports into C++ (86.1%) although Claude Sonnet 5.5 leads overall (86.9% vs 83.3%); Gemini 4 Argon does better in C++ (75.7%) than overall (70.8%); GLM 5.3 drops from 49.6% into Python to 26.9% into C++, below the smaller GLM 5.3 Flash (35.1%); DeepSeek V4.1 Flash 1017 and MiMo-V2.6-Pro are also weaker in C++ than overall. Gemini 4 Neon has no result in either C/C++ column yet.

*Methodology*

Quality ratings prioritize large-repository understanding, complex debugging, code review, long-horizon engineering, and C/C++ correctness. SWE-bench, LiveCodeBench, and other SWE evaluations also inform the qualitative assessment where comparable data exists. The main table uses independent results; where none exists, it shows another independent run (`‡`) or a vendor-reported result (`†`). FC2 has a result for all 25 models; ATLS covers 17 and MC++ 13 (plus Hy4 Preview). SWE-bench Verified, SWE-bench Pro, SWE-bench Multilingual, Aider Polyglot and LiveCodeBench are not shown: they have results for few or none of these models.

*Gemini 4 Neon* ranks #5 with 9.4. It is Google's new middle tier (November 18), placed between Gemini 4 Carbon (long-horizon work) and Gemini 4 Hydrogen (fast everyday work); it replaces neither. Independent results are strong for its price:

- Artificial Analysis Coding Agent Index v2.1: 58.6 at xhigh, #1, level with Fable 5.2 (58.5) and Opus 5.5 (58.2).
- Vibe Code Bench v1.1 (Vals AI): 93.7%, #2, 0.07 points behind Fable 5.2.
- Vals AI Terminal-Bench 4.0: 61.6%, #7, between Carbon (63.1%) and GPT-6.2 Sol (60.6%).
- Artificial Analysis FrontierCode 2.0: 44.4% at xhigh (43.3% at high), level with GPT-6.2 Sol and above Carbon (40.6%).

It has no DeepSWE, FrontierSWE, SWE Atlas or Code Migration result yet, so there is no evidence on long-horizon work or C/C++; Cognition's changelog says Neon was added to FrontierCode 1.1, but no score is shown. In Bito's multi-turn debugging test in Claude Code it scored 79.8%, just behind Carbon (80.7%) and ahead of Sonnet 5.5 (72.3%), at less than half Carbon's session cost ($7.37 vs $16.50); Opus 5.5 led with 86.9%. It ranks below Carbon and GPT-6.2 Astra because it trails them on Terminal-Bench 4.0 and has no long-horizon results, and above Sonnet 5.5 because it leads it on CursorBench, FrontierCode 2.0 and the Coding Agent Index. It has a 1M-token context and four thinking levels (high is the default). It costs $3 / $15 across the whole context: more than Carbon's introductory $2 / $10 but less than Carbon's $4 / $20 from December 1.

*Recommendation for Percona Server for MySQL*

Top candidates for a controlled head-to-head evaluation are *Claude Fable 5.2, Claude Opus 5.5, GPT-6.2 Astra, and Gemini 4 Carbon*. Fable 5.2 is still the strongest model overall and also leads both C/C++ columns (SWE Atlas and ports into C++); compare it at high effort against Opus 5.5 at max effort. GPT-6.2 Astra costs the same as Fable 5.2 and matches it on FrontierCode 2.0, but early reports of stopping early and being hard to steer make it a better candidate for code review than for long autonomous tasks until DeepSWE and FrontierSWE results arrive. Trial Gemini 4 Carbon before its introductory price ends on November 30, and run Gemini 4 Neon next to it: Neon leads CursorBench 4.1 and the Artificial Analysis Coding Agent Index and costs less than Carbon's regular price, but has no C/C++ or long-horizon result yet. Kimi K3.1 Pro remains worth a trial for long-running terminal and agentic tasks. For high-volume work such as test-failure triage and first-pass code review, Gemini 4 Hydrogen, GPT-6.1 Terra and Claude Haiku 5.5 are the cheaper options. Where C++ quality matters more than price, Claude Sonnet 5.5 ($2 / $10) scores 84.4% on ports into C++, far ahead of the cheapest models with a result (DeepSeek V4.1 Flash 1017 55.5%, Claude Haiku 5.5 41.2%, GLM 5.3 26.9%). Test them against real InnoDB concurrency issues, replication bugs, crash recovery, memory-safety problems, complex code reviews, and MTR regression tests.

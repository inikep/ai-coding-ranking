*Recommendation for Percona Server for MySQL*

Top candidates for a controlled head-to-head evaluation are *Claude Opus 5.5, GPT-6 Astra, Gemini 4 Argon, and Claude Sonnet 5.5*. Kimi K3.1 Pro is worth a trial for long-running terminal and agentic tasks, where it leads independent Terminal-Bench results, but it is weaker on precise code changes. Test them against real InnoDB concurrency issues, replication bugs, crash recovery, memory-safety problems, complex code reviews, and MTR regression tests.
